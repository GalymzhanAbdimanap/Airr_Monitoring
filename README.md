# Airr Monitoring 🌬️

**Система мониторинга качества воздуха**

**Airr Monitoring** — это веб-приложение для мониторинга и анализа качества воздуха в городе Алматы. Система предоставляет удобную визуализацию измерений, возможность загрузки данных и базовую аналитику загрязнителей.

---

## 📌 Возможности

* 📊 **Визуализация:** Наглядный просмотр показателей качества воздуха (CO₂, SO₂, NOx, PM и др.).
* 🖥️ **Веб-интерфейс:** Интерактивный UI, реализованный на Streamlit.
* 💾 **Хранение данных:** Использование легковесной базы данных SQLite.
* 📥 **Загрузка данных:** Поддержка ручной загрузки данных (автоматизация сбора планируется).
* 🔮 **Перспективы:** Архитектура готова для будущей интеграции с климатическими моделями WRF/SILAM (в разработке).

## 🛠️ Технический стек

* **Язык:** Python 3.9+
* **Фронтенд/UI:** Streamlit
* **База данных:** SQLite
